## Real bugs found and fixed in reconcileLedger.mjs this session (beyond the earlier race-condition/tolerance fixes)
1. Stored catalog values are per-100g, but ~11 with-photo items had reader2 evidence reported on a per-serving basis. The script originally compared raw per-serving numbers directly against per-100g stored values with no conversion -- added deterministic gram-weight parsing (`parseServingGrams`, restricted to text before the first colon in reader2's notes, to avoid mis-parsing a protein gram figure as a serving weight) and conversion.
2. Some reader2 responses had ALREADY performed that per-100g conversion themselves before writing evidenceCalories/evidenceProtein (despite still labeling basis:'serving'), which caused a double-conversion bug when the script divided by the serving weight a second time. Agent note phrasing for "I already converted" was too inconsistent to detect reliably by regex across all cases -- rather than risk more silent bugs, the ~4 affected items (0814496020035, 0815871010009, 0850010353012, 0856591000062) were resolved individually via `manual_third_read_overrides.json` with the correct arithmetic shown explicitly.
3. Two items had a genuine product-identity conflict surfaced by reader2 (label brand/name text does not match the stored catalog product name: 0075442100229 "Puffed rice" label reads "praline"; 0856591000062 stored as a Hebrew cookie name, label reads "Crispy Bagels - Salt Flavor" by a different brand) -- both resolved to UNRESOLVED rather than accepting the numeric correction, since applying a correction risks attaching the wrong product's evidence to that barcode.
4. Removed an over-eager early-exit that marked anything with reader1 outcome='unresolved' as automatically UNRESOLVED without checking whether reader1 had actually transcribed the same usable numbers reader2 found (common when reader1 read a per-serving-only label correctly but didn't personally do the /serving*100 arithmetic) -- now content-matching checks reader1's text against both raw and converted candidate numbers before giving up.
