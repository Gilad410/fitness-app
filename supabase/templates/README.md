# תבניות המייל של המערכת

התיקייה שומרת עותק מבוקר של המיילים שנשלחים דרך Supabase Auth.

## הזמנה למערכת

- נושא מומלץ: `הזמנה למערכת ניהול הכושר`
- תבנית: `invite.html`
- הגדרה ב-Supabase: Authentication → Emails → Invite user

## איפוס סיסמה

- נושא מומלץ: `איפוס הסיסמה שלך`
- תבנית: `recovery.html`
- הגדרה ב-Supabase: Authentication → Emails → Reset password

בפרויקט המתארח ב-Supabase יש להעתיק את התוכן למסך Email Templates. המשתנה
`{{ .ConfirmationURL }}` חייב להישאר ללא שינוי, משום שהוא מכיל את קישור ההזדהות
האישי. לאחר כל עדכון יש לשלוח הודעת ניסיון לכתובת בדיקה ולבדוק את הקישור גם
בטלפון וגם במחשב.
